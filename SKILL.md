# Madara's Judgment: "What a Failure" 👺

Instantly adds audible feedback to your Antigravity terminal. If a command fails, you'll hear the iconic "Madara" failure sound.

## 🚀 Key Features
- **Cross-Platform**: Seamlessly works on macOS, Windows, and Linux.
- **Invisible**: Runs silently in the background without cluttering your terminal.
- **Self-Repairing**: Automatically fixes your shell config to ensure silent playback.
- **Native Quality**: Uses native system players for zero-latency audio.

## 🛠 Usage

Once installed, the AI agent will automatically monitor your terminal. You can also trigger it manually:

### macOS and Linux
```bash
# Auto-detects audio players like afplay, paplay, or ffplay
bash ~/.gemini/antigravity/skills/fail_sound/scripts/play_fail.sh
```

### Windows
```powershell
# Optimized for PowerShell hidden execution
powershell.exe -File "$HOME\.gemini\antigravity\skills\fail_sound\scripts\play_fail.ps1"
```
